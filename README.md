## 💜 About the Project

Welcome to my personal portfolio website!

I'm **Priyanshi Goyal**, a second-year B.Tech Computer Science Engineering student passionate about software development, problem-solving, Python, C++, and exploring Classical Machine Learning.

This portfolio is my digital space to showcase what I'm learning, what I'm building, and how I'm growing as a developer — one project and one commit at a time.

I designed this website to bring my work together in one place and make it easier for recruiters, fellow developers, and curious visitors to explore my journey.

## ✨ Features

- 🎨 **Modern Dark Theme** — A sleek visual design with vibrant cyan and violet accents.
- 👩‍💻 **Developer Introduction** — A personal introduction highlighting my interests and goals.
- 💫 **Animated Role Text** — Dynamic text showcasing different aspects of my developer journey.
- 🖼️ **Profile Section** — A dedicated space for my introduction and visual identity.
- 🚀 **Projects Showcase** — A collection of my projects with links to explore my work.
- 🤝 **Contact & Social Links** — Quick access to my professional profiles and ways to connect.
- 📱 **Responsive Design** — Built with responsive styling for a better experience across screen sizes.
- ⚡ **Interactive Elements** — JavaScript-powered behavior to make the website more engaging.

## 💻 Run Locally

Want to explore the code or customize the website? Let's go! 🚀

### 1. Clone the repository

```bash
git clone https://github.com/Priyanshi00Goyal/priyanshigoyal.github.io.git
```

### 2. Open the project folder

```bash
cd priyanshigoyal.github.io
```

### 3. Launch the website

Open `index.html` in your browser.

For a smoother development experience, you can open the folder in Visual Studio Code and use the Live Server extension.
